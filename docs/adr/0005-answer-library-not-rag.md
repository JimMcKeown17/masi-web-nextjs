# Grant Writer uses a curated Answer Library, not RAG over past proposals

The Grant Writer drafts applications by recombining ~30-50 curated Answer Blocks — one per question theme, each carrying the canonical narrative in Masi's winning voice, angle variants (jobs-creation vs children's-education emphasis, chosen per funder), live data slots filled from Postgres at draft time, and won/lost tags. A Key Messages checklist (M&E excellence, government partnership, ...) must land somewhere in every application regardless of what was asked. The 20-40 historical Word-doc proposals are ore, not corpus: a one-time agent-assisted distillation (curated by Jim) builds the library, then the documents retire from the runtime path.

Why not RAG/embeddings: the corpus is tiny (the whole library fits in one model context, so there is no retrieval problem to solve), 90% of grant writing is recombination of known answers, and retrieval over old documents would confidently inject stale statistics — the exact failure Jim fears most. Numbers must come only from live data slots, never from retrieved prose.

Consequences: drafting quality depends on library curation, which is deliberate (Jim owns the voice once, staff — non-native English speakers — then produce Jim-quality first drafts through it). The library lives in spine tables and learns: accepted answers from each new application feed back as blocks or variants. Embeddings can be added later if the block count ever makes in-context selection impractical; nothing in the design forecloses it.

Amendment (2026-06-13): the "live data slots" are not a net-new pipeline — the `PublishedStat` registry already in production on `/impact` (model `api/models.py:1526`, endpoint `/impact/published-stats/`, selector `pick(key)`) is the source. Each stat already carries `value`, `numeric_value`, `source_system`, `population`, `comparison_type`, `as_of`, and `methodology_note` — i.e. a citable, dated, sourced number with provenance, which is exactly what a proposal needs and the precise antidote to the stale-statistic failure mode. The slot-fill tool is `published_stats.pick(key)`. Remaining work is curation (verify the seeded/PROVISIONAL values, add the jobs/graduate/retention numbers Jim quotes), not engineering. This is why the Grant Studio is promoted ahead of Funder Research in the rev-2 plan.
